# Security Policy — `receipts-witness`

SPDX-License-Identifier: Apache-2.0

## Reporting a Vulnerability

Please report cryptographic, parser, or protocol vulnerabilities privately to:

- **Email**: `security@hypereum.tech`
- **Response SLA**: Acknowledgment within 24 hours; triage and coordinated remediation plan within 72 hours.

Please do **not** open public GitHub issues for undisclosed security vulnerabilities.
