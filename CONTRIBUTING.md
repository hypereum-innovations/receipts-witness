## Developer Certificate of Origin (DCO 1.1)

Every commit contributed to this repository MUST include a `Signed-off-by` trailer certifying compliance with the [Developer Certificate of Origin (DCO 1.1)](https://developercertificate.org/):

```
Signed-off-by: Random J Developer <random@developer.example.org>
```

Use `git commit -s` to add this sign-off automatically.
